# 百、十、個與位值網頁簡報教材（待確認版）

直接雙擊 `index.html` 即可上課使用，不需要安裝其他程式。

## 操作方式

- 頁面左上方標題為「數學學習站／一步一步學數學」。
- 使用畫面下方的「上一頁／下一頁」切換投影片。
- 沒有在輸入答案時，也可以使用鍵盤左右方向鍵換頁。
- 按「全螢幕」可作為正式上課畫面。
- 按「念題目」會朗讀目前頁面的標題、題目與重點提示。
- 百格板、十條與小積木可用滑鼠拖動。
- 按「換位」按鈕，可示範「10 個十換成 1 個百」或「10 個一換成 1 個十」。
- 練習頁可以填寫答案並按「檢查答案」，也可由教師按「顯示答案」。
- 按「重設本頁」可清除本頁作答並恢復初始狀態。

本資料夾只製作 `02_百十個與位值_自閉症適用版.pptx` 的網頁版，原始簡報與上一份網頁教材均未修改。
